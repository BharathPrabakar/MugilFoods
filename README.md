# Mugil Foods

Official web application for **Mugil Foods** — Purveyors of Premium Tamarind, Cold-Pressed Gingelly & Groundnut Oils, Pure Desi Ghee, and Natural Forest Honey since 2006 (Dharmapuri, Tamil Nadu, India).

## Tech Stack
- React 19
- Vite
- Vanilla CSS with Royal Heritage Design System
- Automated GitHub Actions deployment to GitHub Pages
